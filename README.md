# website_new

Five website designs for **still.**, a fictional natural-wellness brand (demo stores — no real orders).

Live site (GitHub Pages, deployed from the `main` branch, `/ (root)`):
https://nitiikshekhar.github.io/website_new/

```
index.html · styles.css · script.js   landing page linking the five designs
web_1/   Editorial                    index.html · styles.css · app.js
web_2/   Split screen                 index.html · styles.css · app.js
web_3/   Gallery · Mughal garden      index.html · styles.css · app.js
web_4/   Swiss grid                   index.html · styles.css · app.js
web_5/   Bento                        index.html · styles.css · app.js
```

Each `web_N` folder is self-contained — its styles and scripts live only in that folder.
To edit a design's About text, search its `index.html` for `ABOUT THE COMPANY`.
